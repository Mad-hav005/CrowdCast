# CrowdCast

Event demand and overcrowding-risk prediction platform.

## Project Status

Machine learning phase completed. Backend and frontend development are next.

## Structure

- `data/` — datasets
- `src/` — ML and analysis scripts
- `models/` — trained model
- `results/` — evaluation outputs
- `figures/` — generated visualizations
- `backend/` — API layer
- `frontend/` — web application
